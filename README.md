**AppForge Studio** یک نرم‌افزار حرفه‌ای و مدرن دسکتاپ بر پایه **PySide6 (Qt)** است که به توسعه‌دهندگان پایتون امکان می‌دهد پروژه‌های سورس‌کد خود را تنها با چند کلیک به فایل‌های نصبی مستقل **ویندوز (.exe)** یا پکیج‌های نصبی **اندروید (.apk)** تبدیل کرده و در هر مسیر دلخواهی ذخیره نمایند.

---

## 🌟 قابلیت‌های کلیدی

### ۱. 📦 ساخت خروجی‌های حرفه‌ای و مستقل:
- **دسکتاپ ویندوز (.exe):** بر پایه موتور بهینه‌شده `PyInstaller` با قابلیت ساخت فایل تک‌فایلی مستقل (`--onefile`) و مخفی‌سازی کنسول سیاه ویندوز (`--windowed`).
- **اندروید (.apk):** یکپارچه‌سازی کامل با زیرسیستم لینوکس ویندوز (`WSL 2 Ubuntu`) و ابزار قدرتمند `Buildozer`.

### ۲. 🛡️ تضمین اجرای بدون کرش (Runtime Guarantees):
- **اسکن هوشمند وابستگی‌های پنهان (Smart Hidden Imports):** شناسایی خودکار کتابخانه‌های معروفی که به صورت دینامیک لود می‌شوند (نظیر `requests`, `PIL`, `customtkinter`, `uvicorn`, `fastapi`, `sqlalchemy`, `matplotlib`, `pandas`, `pygame`, `pydantic`, `rich`, `cryptography`, `selenium`, ...) و اعمال خودکار فلگ‌های `--collect-all` و `--hidden-import`.
- **تست سلامت زنده اولیه (Pre-flight Smoke Test):** اجرای آزمایشی فایل `.exe` بلافاصله پس از کامپایل در پس‌زمینه؛ در صورت هرگونه کرش یا کمبود ماژول، گزارش و راهنمای دقیق در لاگ‌ها چاپ می‌شود.
- **تولید خودکار اسکریپت نصاب ویندوز (Inno Setup):** تولید یک اسکریپت نصاب رسمی (`setup_MyApp.iss`) برای ایجاد فایل نصبی با ویزارد نصب، آیکون دسکتاپ و کنترل پنل ویندوز.
- **راهنمای مسیر امن فایل‌ها (Resource Path Guide):** ارائه قطعه کد استاندارد جهت جلوگیری از خطای `FileNotFoundError` در فایل‌های تک‌فایلی.

### ۳. 🔄 سیستم بررسی خودکار و هوشمند بروزرسانی (In-App Auto Update Checker):
- اتصال خودکار به مخزن گیت‌هاب [`raza6589his-collab/Appforge`](https://github.com/raza6589his-collab/Appforge) در پس‌زمینه بدون کندی سرعت برنامه.
- به محض انتشار نسخه جدید در بخش Releases گیت‌هاب، یک بنر مدرن در بالای نرم‌افزار به کاربر اطلاع می‌دهد.
- امکان مشاهده لیست تغییرات نسخه جدید (Changelog) و دانلود مستقیم فایل نصبی با یک کلیک.
- دکمه بررسی دستی در نوار وضعیت پایین برنامه (`Footer Status Bar`).

### ۴. 🎨 طراحی مینیمال تجاری و پیشرفته:
- تم تاریک استاندارد مهندسی (الهام‌گرفته از Linear و GitHub Dark).
- مدیریت کامل آیکون‌ها: تبدیل خودکار هر نوع تصویر (PNG/JPG/WEBP) به آیکون چندوضوحی ویندوز (`.ico`) با پیش‌نمایش گرافیکی.
- شناسایی خودکار پوشه‌های رسانه‌ای و فایل‌های جانبی (`assets`, `static`, `images`, `data`, ...) و الحاق خودکار آن‌ها به پکیج با دستور `--add-data`.
- ثبت شناسنامه رسمی و مشخصات نسخه ویندوز (`VS_VERSION_INFO`) شامل نام شرکت، توضیحات و حق کپی‌رایت.
- ذخیره و بازیابی هوشمند تنظیمات در قالب فایل `appforge.json` داخل پوشه پروژه.

## 🚀 راهنمای نصب و راه‌اندازی سریع

### ۱. کلون کردن مخزن:
```bash
git clone https://github.com/raza6589his-collab/Appforge.git
cd Appforge
```

### ۲. نصب پیش‌نیازهای پایتون:
```bash
pip install -r requirements.txt
```

### ۳. اجرای نرم‌افزار:
- **روش اول:** دابل کلیک روی فایل `run_appforge.bat`
- **روش دوم:** اجرای دستور در ترمینال:
```bash
python main.py
```

## 📦 نحوه انتشار نسخه جدید در گیت‌هاب (برای ارسال نوتیفیکیشن به کاربران)

به دلیل وجود ورک‌فلو خودکار گیت‌هاب (`GitHub Actions`) در این مخزن، هر زمان که ویژگی جدیدی به برنامه اضافه کردید، تنها کافیست یک تگ نسخه بسازید و پوش کنید:

```bash
git tag v1.0.1
git push origin v1.0.1
```

یا از طریق منوی **Releases -> Draft a new release** در صفحه گیت‌هاب:
1. تگ جدیدی مانند `v1.0.1` ثبت کنید.
2. توضیحات تغییرات را بنویسید.
3. فایل نصبی نسخه جدید را ضمیمه کرده و دکمه **Publish release** را بزنید.

**نتیجه:** کاربران برنامه هنگام باز کردن نسخه قبلی، بنر بروزرسانی نسخه `v1.0.1` را همراه با دکمه دانلود مستقیم دریافت خواهند کرد!
